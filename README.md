Web-based multi-tool platform — handy everyday tools in one clean, fast website.

## Features
- Resume Builder
- Unit Converter
- Word Counter
- QR Code Generator
- Plagiarism Checker
- File Converter

## Tech Stack
HTML · CSS · JavaScript

## Run
Open `index.html` in any browser.
